    Examples¶

    The guided pages include rendered plots and expandable code that creates them. Read the charts first; expand the code to reproduce them, running blocks in page order. Start with a guided example, then use the standalone scripts to investigate one assumption at a time. There are eight guided pages and 87 runnable scripts. The scripts retain their historical filenames; the titles below describe what you will learn. Original MATLAB coverage is tracked separately in the translation map.

    Set up and run¶

    From a local checkout, install the package and plotting dependencies:

    python -m pip install -e ".[viz]"
python docs/examples/backtest/backtest3.py

    Guided pages contain Python blocks meant to run in order in one session. Each standalone script starts fresh and embeds its data or uses a fixed random seed. Numerical results may differ slightly with solver and library versions. A seed makes a demonstration reproducible; it does not validate the model.

    To check every script and guided page in fresh processes, without opening plots:

    python scripts/check_examples.py

    To regenerate the guided pages’ figures directly from their displayed code:

    python scripts/check_examples.py --render-plots --pattern "*.md" --report reports/guided-examples-execution.json

    The report in reports/examples-execution.json records output, warnings, completion status, and duration. A successful exit is an execution check; read convergence flags and model diagnostics before interpreting estimates.

    Choose a learning path¶

    Path Read first Continue with
    Pricing and allocation Bonds → Mean-variance Risk budgets → Black-Litterman
    Numerical foundations Building blocks Matrix identities, constraint conversion, and finite differences below
    Statistical estimation Regression Quantile regression → local-level Kalman models → Whittle
    Classification SVM geometry Dual hard margins → soft margins → SVM regression
    Backtesting backtest3.py below Funding round trip → rebalance schedules → transaction costs

    Use decimal returns and weights unless an output explicitly says percent. Keep return and covariance horizons consistent. For fitted models, distinguish training fit, numerical convergence, and performance on unseen observations.
